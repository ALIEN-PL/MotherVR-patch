# MotherVR patched DLL for WinlatorXR (epic and steam version-untested)
## Installation
Drag the dxgi.dll into your Alien: Isolation game folder. To Enable VR, you can do so in Options->MotherVR after the game starts up. 

For epic game store version run with args -EpicPortal in WinlatorXR shortcut after installation

## Settings
Done in the in-game Options menu.
